# Course requirements for the final report (summary; formatting handled later)

- NeurIPS style; core 5–10 pages; references and appendices unlimited. No padding; AI slop is penalized.
- Must have: short abstract; introduction with background and related work; methods; results with plots; conclusion/discussion.
- Extend and update the proposal. Mark in-progress items in the draft.
- Literature review: detailed, ~2–3 full pages on related work.
- Self-contained math; fully labeled diagrams; pseudocode where clearest.
- Hyperparameter tables with how/why each value was chosen (cite if taken from papers; otherwise back with experiments, can be in appendix).
- Plots with error bars as appropriate; explain how error bars are made and why; explain the axis scale choice. Include a training curve and some validation loss.
- Experiments controlled where practicable (change one thing at a time); commentary on this is required.
- Explain techniques not covered in the course at peer level.
- Public GitHub that reproduces all plots and tables; code fetches public datasets.
